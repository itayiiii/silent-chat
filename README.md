# 🎧 שיחה שקטה

אפליקציה שמאפשרת לחברים שיושבים יחד בסביבה רועשת (למשל מסעדה) לשמוע זה את זה בבירור דרך אוזניות. כל אחד מתחבר עם הטלפון שלו לחדר משותף, והאודיו עובר ישירות בין הטלפונים (WebRTC).

**האפליקציה:** https://itayiiii.github.io/silent-chat/

## התקנה בטלפון

- **אנדרואיד (כרום):** פותחים את הקישור ← לוחצים "📲 התקן כאפליקציה" ← "התקנה". האייקון יופיע במסך הבית.
- **אייפון / אייפד:** פותחים את הקישור ← כפתור שיתוף ⬆️ ← "הוסף למסך הבית".

לא צריך חשבון GitHub, לא צריך חנות אפליקציות. מי שיש לו את הקישור יכול להשתמש.

## אפליקציית אנדרואיד (APK) לבודקים

**הורדה:** https://github.com/itayiiii/silent-chat/releases/download/test-build/silent-chat.apk

פותחים את הקישור בטלפון ← פותחים את הקובץ שירד ← מאשרים התקנה ממקור לא ידוע (ואם Play Protect מזהיר: "התקן בכל זאת").
מגרסה 0.1.5 כל הגרסאות חתומות באותו מפתח בדיקה, אז גרסה חדשה מותקנת **מעל** הקודמת — בלי להסיר (רק המעבר מ-0.1.4 ומטה ל-0.1.5 דורש הסרה אחת אחרונה).

ב-APK השיחה ממשיכה גם כשהמסך כבוי: בזמן שיחה מוצגת התראה "שיחה פעילה" שמשאירה את המיקרופון פועל.
מגרסה 0.1.6 האפליקציה מבקשת גם אישור למצלמה — רק כדי לסרוק את קוד ה-QR של חדר.
הקוד שבתוך ה-APK מעורבל (obfuscated), כך שקשה לקרוא או להעתיק אותו.

## איך מצטרפים לחדר (בלי מספרים שאפשר לנחש)

- **צור חדר חדש** — נפתח חלון "הזמנת חברים" עם **קוד QR**. בתוך הקוד יש מפתח סודי ואקראי של 16 תווים (80 ביט) — אי אפשר לנחש אותו או "להריץ מספרים".
- **הצטרף לחדר** — המצלמה נפתחת, מכוונים לקוד ונכנסים לבד.
- **💬 שלח הזמנה בוואטסאפ** — וואטסאפ נפתח עם הזמנה מוכנה; כל מי שמקבל לוחץ על הקישור ונכנס (גם בלי להתקין — בדפדפן).
- **🔢 מספר של 4 ספרות** (מתחת לקוד) — מי שמקליד אותו **דופק בדלת**: אצלו מופיע סימן (2 ציורים), ואצל מי שבחדר קופץ "מישהו דופק בדלת" עם אותו סימן. החבר אומר "כן, זה אני" ומישהו לוחץ "הכנס". אחרי שנכנס — הוא מתבקש לנעול את החדר.
- **🔒 נעילה** — כשהחדר נעול, כל מי שמגיע (מספר, קוד או קישור) דופק בדלת ומישהו מבפנים מכניס אותו. מי שכבר היה בחדר ונפל חוזר לבד. כל מי שבחדר יכול לנעול ולפתוח.
- בשרת: מי שמנסה הרבה מפתחות או מספרים שגויים נחסם ל-10 דקות; עד 8 משתתפים בחדר; ביומן השרת מופיעים רק 4 תווים מכל חדר (בלי המספר).

## איך זה בנוי

| חלק | איפה רץ | תפקיד |
|------|---------|--------|
| `index.html` + `manifest.json` + `sw.js` + `icons/` | GitHub Pages (חינם) | האפליקציה עצמה |
| `lib/` | GitHub Pages | ספריות קוד ה-QR: ציור (qrcode-generator, MIT) וקריאה מהמצלמה (jsQR, Apache-2.0) — ראו `lib/LICENSES.md` |
| `ai-worker.js` + `ai/` | GitHub Pages | "🧠 בינה מלאכותית" לזיהוי הקול: המנוע (ONNX Runtime Web) והמודל (CAM++) — כ-44MB שיורדים פעם אחת, רק כשבוחרים בבינה (ראו `ai/README.md`) |
| `server.js` + `package.json` | Render.com (חינם) | "מרכזייה" שמחברת בין הטלפונים בתחילת השיחה. האודיו עצמו לא עובר דרכה |
| `mobile/` | GitHub Actions (חינם) | בונה את ה-APK: מעתיק את `index.html` בגרסה מעורבלת לתוך אפליקציית אנדרואיד (Capacitor) |

כל שינוי שנשמר ב-`main` מתעדכן אוטומטית: GitHub Pages מעדכן את האפליקציה תוך דקה-שתיים, Render מעדכן את השרת, ושינוי באפליקציה עצמה בונה APK חדש באותו קישור הורדה.

## מצבי סינון

🔊 כבוי · 🎵 בסיסי (סינון רעש של הדפדפן) · 🧬 זיהוי קולי (ניסיוני, למעלה מימין) · 🎯 חכם (עובר רק קול חזק) · 🎙️ לחץ ודבר

ב**זיהוי קולי** בוחרים מנגנון (רישום אחד של 5 שניות מלמד את כולם, והכל נשאר בטלפון):

| מנגנון | איך | בבדיקה (הקלטות נקיות: דובר רשום / דובר אחר) |
|---|---|---|
| ⚡ טביעת קול | גובה הצליל + "צבע" הקול (המנגנון הישן) | 95–98% / 85–92% עברו — מתבלבל בקלות |
| 📊 מודל קול | MFCC + מודל סטטיסטי (הדרך הקלאסית לזיהוי דוברים), מחליט תוך ~0.2 שנ׳ | 73–86% / 0–4% |
| 🧠 בינה מלאכותית | רשת נוירונים CAM++ בתוך הטלפון, בודקת כל משפט (הורדה חד-פעמית של 44MB) | 90–99% / 0% |
| 🛡️ שילוב (ברירת מחדל) | מודל הקול פותח מיד, הבינה מאשרת או סוגרת אחרי חצי שנייה | 97–99% / 0–3% |

מתחת למצבים יש כרטיס **כיוון אישי**: סף פתיחה שגוררים ביד (או סף אוטומטי לפי הרעש סביבך), זמן החזקה, כמה קפדני זיהוי הקול, וב"מתקדם" — הסינונים של הטלפון ו"רק תדרי דיבור". הכל נשמר בטלפון.

⚙️ במסך הבית: **כפתורים ותנועה** — כפתורים בתלת־ממד (ברירת המחדל) או שטוחים, ותנועות לבחירה.

## מגבלות ידועות

- השרת החינמי ב-Render "נרדם" אחרי 15 דקות בלי שימוש. בכניסה הראשונה אחרי זה לוקח בערך דקה עד שהוא מתעורר.
- עד 4-5 משתתפים בחדר (כל טלפון שולח אודיו לכל השאר).
- בגרסת הדפדפן, כשהמסך כבוי השיחה תלויה בדפדפן. באפליקציית האנדרואיד היא ממשיכה לעבוד (ראו למעלה).
- באייפון האודיו עלול להיעצר כשהמסך נעול.
